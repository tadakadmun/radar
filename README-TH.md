# NavAssist รุ่นปรับปรุงแบบไม่ใช้บริการเสียเงิน

ปรับปรุงวันที่ 28 กันยายน 2026

## เริ่มใช้งาน

1. สำรองโฟลเดอร์เว็บเดิมไว้ก่อน
2. เปิดไฟล์ `navassist-download.html` ด้วย Chrome หรือ Edge บน Windows แล้วกด **บันทึกทั้งชุดลงโฟลเดอร์** เลือกโฟลเดอร์ว่าง โปรแกรมจะสร้างไฟล์และโฟลเดอร์ให้ ไม่ต้องแตก ZIP และไม่ต่ออินเทอร์เน็ตระหว่างบันทึกไฟล์
3. หากปุ่มบันทึกโฟลเดอร์ใช้ไม่ได้ ให้กดชื่อไฟล์แต่ละรายการ แล้ววางตามคอลัมน์ “ตำแหน่ง” อย่าให้ชื่อไฟล์มี `(1)` ต่อท้าย
4. นำไฟล์ทั้งชุดไปแทนในพื้นที่เว็บ HTTPS เดิมที่ใช้งานฟรีอยู่ รักษาโครงสร้าง `js/` และ `icons/` ห้ามวาง JavaScript ทุกไฟล์ไว้ข้าง index.html
5. ปิดหน้าเว็บและแอป NavAssist เดิมทุกหน้าก่อนเปิดใหม่ หากยังแสดงรุ่นเก่า กด **ซ่อมไฟล์แอป** ขณะเชื่อมต่อ Wi-Fi แล้วปิดทุกหน้าและเปิดใหม่อีกครั้ง
6. กด **เตรียม AI ฟรีผ่าน Wi-Fi** ครั้งแรกประมาณ 27 MB รอข้อความว่าไฟล์แอปและ AI พร้อมออฟไลน์แล้ว ไม่ต้องสมัครสมาชิก ใส่บัตร หรือซื้อ API
7. ขณะจอดรถ เปิดตั้งกล้อง อนุญาตกล้อง ปรับเส้นบนภาพจริง และกดยืนยัน จากนั้นกดเริ่มและอนุญาตตำแหน่ง
8. เมื่อเตรียมไฟล์ครบแล้ว การตรวจภาพทำบนเครื่อง ใช้แบบออฟไลน์ได้ ปิดข้อมูลถนนออนไลน์ไว้หากไม่ต้องการใช้เครือข่าย

`navassist-download.html` เป็นตัวช่วยบันทึกไฟล์ ไม่ใช่ตัวแอปที่จะอัปโหลด หน้าใช้งานจริงคือ `index.html` บน HTTPS การดับเบิลคลิก index.html จากโฟลเดอร์จะใช้กล้องและระบบออฟไลน์ไม่ได้ครบ

## โครงสร้าง

- โฟลเดอร์หลัก: index.html, style.css, manifest.json, sw.js
- js/: main.js, ui.js, camera.js, detector.js, detector-worker.js, assets.js, offline.js, tracker.js, lane.js, vision.js, alerts.js, geo.js, osm.js, store.js, health.js, calibrate.js, util.js
- icons/: icon-192.png, icon-512.png, icon-maskable-512.png
- README-TH.md: เอกสารฉบับนี้ ไม่จำเป็นต่อการรัน

manifest.json และ vision.js รวมมาเพื่อให้ครบชุด โดยไม่ได้เปลี่ยนเนื้อหาจากต้นฉบับ ไฟล์อื่นเป็นไฟล์แก้ไขหรือไฟล์ใหม่

## สิ่งที่แก้

- คำเตือนระดับวิกฤตแทรกคำเตือนระดับต่ำกว่าได้ทันที แม้ยังอยู่ในเวลาพักคำเตือนเดิม
- ไม่ปลดล็อกการตั้งค่าเพียงเพราะ GPS ขาดหาย ต้องมีความเร็วหยุดนิ่งต่อเนื่องจึงปลดล็อกอัตโนมัติ และไม่รับข้อมูลตำแหน่งเก่าซ้ำ
- ปิดกล้องและตัวประมวลผลเมื่อเริ่มไม่สำเร็จ กดหยุด หรือสลับออกจากแอป
- แยกการประมวลผล AI ไปยัง Worker ลดการขวางการทำงานของหน้าจอ
- ตรวจทั้งความสดของเฟรมกล้องและผล AI ภาพไม่ชัด ผลช้า หรือยังไม่ยืนยันกล้อง จะพักการเตือนจากภาพ
- หน้าตั้งกล้องแสดงภาพและเส้นอ้างอิงอยู่ด้วยกัน การเลื่อนค่าจะยกเลิกการยืนยันเดิม ต้องยืนยันอีกครั้ง
- ไม่แสดงระยะวัตถุเป็นเมตรจากค่าขนาดวัตถุและระยะโฟกัสที่เดา ไม่มีคำรับรองความเร็วเข้าโค้งที่ปลอดภัย
- แยกไฟล์ AI ออกจากแคชหน้าเว็บ เก็บไว้เมื่ออัปเดตแอป ไม่ลบแคชเว็บอื่น และไม่เก็บ HTTP 503 เป็นไฟล์ใช้งาน
- โหลด AI เฉพาะเมื่อกดเตรียมไฟล์ ตรวจไฟล์ครบก่อนเริ่ม หากโหลดไม่ครบกดเตรียมซ้ำเพื่อโหลดเฉพาะส่วนที่ขาดได้
- ปิด OSM โดยค่าเริ่มต้น หากเปิด จะส่งกรอบพื้นที่โดยประมาณไปยังบริการ Overpass สาธารณะ ไม่มีการส่งภาพกล้อง
- จับคู่ถนนจากทิศ GPS ที่สดและแม่นยำ ปฏิเสธถนนใกล้กันที่แยกไม่ออก ตรวจรูปแบบแคชเก่าก่อนใช้ และรายงานการบันทึกข้อมูลล้มเหลว

## เงื่อนไขไม่มีบริการเสียเงิน

โค้ดไม่ใช้ API แบบคิดเงิน ไม่มีค่าสมาชิก ไม่มี API key และไม่มีหน้ากรอกบัตร AI ประมวลผลบนเครื่องผ่าน MediaPipe และโมเดลสาธารณะ การเตรียมครั้งแรกยังต้องดาวน์โหลดไฟล์ ใช้ Wi-Fi ที่มีอยู่เพื่อไม่เพิ่มการใช้ดาต้ามือถือ ขนาดจำกัดข้อมูล OSM เป็นประมาณการ ไม่ใช่การจำกัดยอดค่าบริการเครือข่าย

ไม่ได้สมัครโฮสติ้งหรือซื้อโดเมนให้ และไม่ได้เปลี่ยนแพ็กเกจบริการใด ๆ หากเบราว์เซอร์ล้างข้อมูลเว็บไซต์หรือพื้นที่เต็ม อาจต้องเตรียม AI ใหม่ผ่าน Wi-Fi บริการดาวน์โหลดสาธารณะอาจขัดข้องได้ แอปจะบอกข้อผิดพลาด ไม่เปลี่ยนไปใช้บริการเสียเงินอัตโนมัติ

## ผลทดสอบและขอบเขต

- ตรวจไวยากรณ์ JavaScript ทุกไฟล์ผ่าน
- ชุดทดสอบข้อผิดพลาด 11 กลุ่มผ่าน: การเพิ่มระดับคำเตือน, GPS หาย/ข้อมูลเก่า/ช่วงหยุดไม่ต่อเนื่อง, ภาพไม่ชัดและการยืนยันกล้อง, ภาพค้าง/ผลเก่า, คืนกล้องเมื่อเปิดไม่สำเร็จ, ค่าตั้งกล้อง, ไฟล์หลักติดตั้งไม่ครบ, การรักษาแคชอื่นและ AI, ไม่โหลดโมเดลเอง, HTTP 503 ไม่ปนแคช, และเตรียมไฟล์จริงครบ 6 รายการ
- ทดสอบ Chromium 145 บน Linux ด้วยกล้องจำลอง: หน้าเว็บเปิดได้ ปุ่มเตรียมทำงาน เห็นภาพพร้อมเส้นตั้งกล้อง กดหยุดแล้วคืนกล้อง ไม่มีข้อผิดพลาด JavaScript ที่ไม่ถูกจัดการ
- โหลดโมเดลจริงและประมวลผลภาพทดสอบได้ใน Worker โดยใช้ GPU; เปิดหน้าใหม่และโหลดโมเดลได้หลังตัดอินเทอร์เน็ต
- ในการทดสอบเบราว์เซอร์ นำไฟล์ AI จริงที่ดาวน์โหลดตรวจสอบไว้ใส่แคชก่อน ไม่ได้ทดสอบการดาวน์โหลดครบชุดผ่าน CDN จาก iPhone ส่วนขั้นตอนเตรียมไฟล์ทดสอบแยกด้วย Service Worker จำลองและไบต์ไฟล์จริง
- ภาพทดสอบเป็นภาพว่าง/กล้องจำลอง ไม่ใช่หลักฐานความแม่นยำในการตรวจรถหรือเลน การประมวลผลภาพแรกในสภาพแวดล้อมทดสอบใช้ประมาณ 2.4 วินาที ผลที่ช้าเกินเกณฑ์จะถูกระงับ ไม่ใช่ผลวัดสมรรถนะโทรศัพท์จริง

ยังไม่ได้ทดสอบบน iPhone/Safari จริงหรือบนถนนจริง แอปนี้ยังเป็นต้นแบบช่วยเตือน อาจเตือนผิดหรือไม่เตือน ผู้ขับต้องมองถนนและควบคุมรถเอง ไม่มีระบบเบรกหรือควบคุมรถ การสลับแอปจะหยุดระบบ ต้องจอดและเริ่มใหม่ การเปิดหน้าใหม่ต้องยืนยันแนวกล้องใหม่

## สิ่งที่ควรพัฒนาต่อโดยไม่ซื้อบริการ

1. ทดสอบด้วยคลิปถนนที่มีสิทธิ์ใช้งาน แยกกลางวัน/กลางคืน/ฝน/โค้ง และบันทึกจำนวนเตือนผิดกับเหตุการณ์ที่พลาดก่อนปรับเกณฑ์
2. ทดสอบ iPhone จริงเรื่อง Worker กล้อง เสียงพูดไทย ออฟไลน์ และความร้อน ประเมินเวลาประมวลผลต่อเนื่องก่อนพิจารณาเปลี่ยนโมเดล
3. ปรับปรุงการติดตามวัตถุและการแยกการเคลื่อนที่ของกล้องด้วยชุดทดสอบที่ตรวจซ้ำได้ ค่าประมาณเวลาปะทะยังอาศัยสมมติฐานจากขนาดวัตถุในภาพ
4. ตรวจข้อมูลถนนกับป้ายจริงในพื้นที่ใช้งาน OSM อาจไม่มีข้อมูลหรือไม่ทันสมัย ให้ป้ายจริงเป็นหลัก

หากแก้โค้ดและปล่อยรุ่นใหม่ในอนาคต ต้องเปลี่ยนชื่อ SHELL_CACHE ใน sw.js เพื่อแยกไฟล์แต่ละรุ่น แล้วตรวจการอัปเดตโดยปิดหน้าแอปเก่าทุกหน้าก่อน
